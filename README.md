# 🌱 Proyecto Huerta Inteligente

Este proyecto muestra un sistema de monitoreo de estrés hídrico en plantas usando Arduino.

## Funcionalidades
- Página principal con explicación y simulador
- Calendario de siembra por estaciones
- Diseño responsive
- Interacción con JavaScript
